🩺 Lung Cancer Detection using Patient Diagnosis Data
📘 Overview
This project aims to build a Machine Learning model that predicts whether a lung cancer patient will survive based on diagnostic and treatment-related data.
By analyzing multiple health parameters like age, smoking status, BMI, treatment type, and cancer stage, the system helps in understanding key survival factors and assists healthcare professionals in decision-making.

🎯 Objective
To develop a predictive model that determines the survival status of lung cancer patients using their medical diagnosis data.
